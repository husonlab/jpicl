## New features

New PICL feature -m Added bootstrap across trees:  new option in settings file Boot_type is set to 1 for tree bootstrap,
and to 2 for branch length bootstrap on a fixed tree

## Known issues

PICL's method write_species_tree_boot in boot.c has a copy-paste bug — for a non-root cherry it writes the internal
branch length to out instead of boot,
so one length can land in the wrong file. JPICL contains a workaround.

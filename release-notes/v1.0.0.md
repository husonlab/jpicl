# JPICL 1.0.0

First public release of JPICL, a Java-based graphical user interface for the PICL phylogenetic inference program written
in C.

This release provides:

- a cross-platform desktop interface implemented in Java/JavaFX
- integration of the native PICL executable
- packaged installers for macOS, Windows, and Linux
- automatic update support

The project aims to make PICL more accessible to users through a modern graphical environment for configuring analyses,
running computations, and inspecting results.

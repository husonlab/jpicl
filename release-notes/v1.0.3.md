# JPICL 1.0.3

## New features

- Updated to new release of PICL
- PICL added support for the new CIS/multilocus model (MSC-JC69) with variable population size (model=5).
  When using model=5, an additional input parameter, lambda, must be specified. It appears immediately after theta in
  the list of model parameters.
  A recommended default value is 300.

## Known issues

- Windows binary might still crash: workaround compile your own windows picl binary and
  supply it using the Executable section of the Log pane.
